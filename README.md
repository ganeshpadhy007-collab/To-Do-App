## Task Management Web App

Live Demo: [Click Here](https://ganeshpadhy007-collab.github.io/To-Do-App/)

### Features
- **CRUD Operations:** Add, Edit, Delete, and Mark tasks as complete
- **Data Persistence:** Tasks saved in browser using LocalStorage API
- **Task Filtering:** Filter by All, Active, and Completed tasks
- **Bulk Actions:** Clear all completed tasks at once
- **Clean UI:** Minimalist design with smooth animations
- **Fully Responsive:** Works seamlessly on mobile and desktop

### Tech Stack
- HTML5 for structure
- CSS3 for styling and animations
- Vanilla JavaScript for functionality
- LocalStorage API for data persistence

### Key Learnings
- DOM manipulation and event delegation
- Working with browser LocalStorage
- Managing application state without frameworks
- Writing clean, maintainable JavaScript code
